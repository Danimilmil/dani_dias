Uma visão geral
Sou estudante de Informática para Web na ETEC Cidade Tiradentes, em São Paulo, e estou construindo minha carreira na interseção entre desenvolvimento, qualidade e infraestrutura.

Meu foco é compreender o ciclo completo de uma solução: como ela é planejada, construída, testada, documentada e preparada para evoluir. Por isso, estudo tecnologia de forma conectada — código, dados, testes, ferramentas e processos fazem parte da mesma visão.

Não quero apenas fazer uma aplicação funcionar. Quero entender por que ela funciona, onde pode falhar e como torná-la mais confiável.
